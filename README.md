# Rodel-Mobility

Mobility-App für Rennrodler: rotierendes Tagestraining (A Rücken, B Hüfte, C Beinrückseite),
Wettkampfprogramm vor und nach dem Lauf, 28 animierte Übungen, Vorbeuge-Test.
Läuft komplett im Browser, funktioniert nach dem ersten Öffnen auch offline.

## Auf GitHub hochladen (am Computer, ca. 5 Minuten)

1. Auf https://github.com anmelden (oder kostenloses Konto anlegen).
2. Oben rechts **+ → New repository**.
   - Name: `rodel-mobility`
   - **Public** auswählen (GitHub Pages ist nur bei öffentlichen Repositories kostenlos)
   - **Create repository**
3. Auf der neuen Seite **uploading an existing file** anklicken.
4. Die ZIP-Datei entpacken und **den Inhalt des Ordners** (nicht den Ordner selbst) ins Browserfenster ziehen:
   `index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, `README.md` und den Ordner `icons`.
   Tipp: Die Datei `.nojekyll` ist eventuell versteckt. Sie ist nicht zwingend nötig.
5. Unten **Commit changes** klicken.
6. **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main**, Ordner **/ (root)** → **Save**
7. 1–2 Minuten warten. Oben auf der Pages-Seite erscheint die Adresse, z. B.
   `https://DEIN-NAME.github.io/rodel-mobility/`

## Auf dem Android-Handy installieren

1. Die Adresse in **Google Chrome** öffnen.
2. Entweder erscheint in der App oben der Hinweis **„Als App installieren"**, oder:
   Menü **⋮ → App installieren** (bei manchen Versionen: **Zum Startbildschirm hinzufügen**).
3. Die App liegt jetzt mit eigenem Symbol auf dem Startbildschirm und öffnet sich im Vollbild.
4. Einmal online öffnen, danach funktioniert sie auch ohne Netz (z. B. an der Bahn).

## Updates einspielen

Neue Version der Dateien im Repository hochladen (gleiche Namen, **Commit changes**).
Die App holt sich die neue Version beim nächsten Öffnen mit Internet automatisch.
Falls nicht: App schließen und noch einmal öffnen.

## Daten

Alle Einheiten, Tests und Einstellungen bleiben nur auf dem Handy.
Unter **Einstellungen → Datensicherung → Exportieren** kannst du eine Sicherungsdatei speichern
und auf einem neuen Handy mit **Importieren** wieder einlesen.
